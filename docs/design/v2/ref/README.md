# V2-Referenz-Screenshots (AP1i, E14)

Die 19 Zustände des V2-Mockups, aufgenommen am 11.09.2026 bei 1440×900.
Sie sind die verbindliche Messlatte für PR 3 (Tokens/Shell) und die PRs 5–8;
Abweichungen der Implementierung werden gegen diese Bilder geprüft.

- Format: WebP, **verlustfrei** (`cwebp -lossless`) — pixelgenau vergleichbar.
- Benennung: `screen_zustand_theme.webp`; `standard` ist der Ausgangszustand
  eines Screens ohne geöffnete Overlays, Theme ist `light` oder `dark`.
- Quelle ist das V2-Mockup-Projekt (Claude Design, siehe Delta-Bericht AP1i);
  die Screenshots ersetzen den session-lokalen Scratchpad-Stand.

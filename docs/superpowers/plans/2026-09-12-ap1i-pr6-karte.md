# AP1i PR 6 — karte. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** karte. im V2-Look: Vollbreite MapLibre-Karte mit Glas-Toolbar
(Suche, sicht-Umschalter, Facetten-Filter), flachen V2-Markern mit
Aggregation, Glas-Legende mit Regionsschaltern, Lime-Regionsumrissen und
Zwei-Schritt-Zeichnen-Dialog.

**Architecture:** Der Karten-Datenpfad läuft komplett über die getesteten
PR-3-Mapper (`ladeStroeme` → `Strom[]`), gefiltert mit `filterStroeme` aus
demselben Querystring-Schema wie ströme./auswertung. — `listMapPunkte` mit
seinen `sql<number>`-Behauptungen entfällt. Alles Kartenspezifische
(Punkt-Mapping, Aggregation, Größen, Suche, Bbox-Mathe) liegt pur und
getestet in `lib/karte-modell.ts`; die MapLibre-DOM-Arbeit in schmalen
Client-Komponenten unter `components/karte/`.

**Tech Stack:** MapLibre GL (bestehend, kein Leaflet — Delta-Bericht 4.1),
Next.js App Router, Vitest. Keine neuen Laufzeit-Abhängigkeiten.

**Spec:** Auftragstext Eric (Chat, 2026-09-12) + `docs/ap1i-delta-v2.md`
(§1.4, §6, §8) + `docs/design/v2/ref/karte_standard_{light,dark}.webp`.

## Global Constraints

- MapLibre bleibt; Optik/Verhalten des Mockups werden nachgebaut, keine Bibliothek gewechselt, nichts zur Laufzeit extern nachgeladen (OSM-Tiles wie bisher).
- Marker: Biomasse Kreis, Output Raute, flach gefüllt (Cluster-/Gruppenfarbe aus `lib/farben.ts`), Größe 12–38 px nach Menge, Rand 1 px Qualitätsfarbe auf 55 % Deckkraft, weicher Schatten; Rand bleibt 1 px auch aktiv (nur Farbe markiert).
- Datenfilter im Querystring, mehrwertig kommagetrennt, Parameter wie ströme./§6; neu `sicht=alle|feedstock|outputs`. Legende (auf/zu, Höhe, Regionsschalter) im Cookie `bhyo_ui`.
- Eine `sql<T>`-Annotation ist keine Konvertierung: Konvertierung an genau einer Stelle in einem reinen, DB-freien Modul, Tests in beiden Treiber-Formen; keine stummen Fallbacks (unerwartete Formate → `console.error`).
- Keine neuen Laufzeit-Abhängigkeiten, Fonts nur next/font, Light + Dark Pflicht, keine Migration; Mockup-Lücken in den PR-Text, nicht raten.
- `components/Karte.tsx` bleibt UNVERÄNDERT (BewertungPanel nutzt sie bis PR 8); `FilterBar`/`DetailPanel` bleiben für auswertung. (bis PR 7).

## Bewusste Interpretationen (in den PR-Text übernehmen)

1. Marker sind FLACH (Eric-Spec) — die Orb-PNG-Optik aus Delta 1.4 gilt nur
   für den 32-px-Orb im Marker-Panel.
2. Karten-Suche findet, was geladen ist: Ströme (Titel/Akteur/Ort/Materialart),
   Fokusregionen (Name) und Orte (DISTINCT aus den Strömen). Kein Geocoding,
   keine Laufzeit-API.
3. Legende: Cluster-/Gruppen-Zeilen tragen Counts der sichtbaren Marker und
   filtern per Klick (Delta 1.4); dafür bekommt `StroemeFilter` die Facette
   `gruppe` (Output-Gruppe) — nur karte./auswertung. nutzen sie vorerst.
4. „Link nach auswertung." = die Sidebar-Links karte. ↔ auswertung. tragen die
   geteilten Datenfilter-Parameter weiter, wenn man zwischen den beiden Views
   wechselt.
5. Aggregations-Fächer öffnet nach oben (−90°-Bogen, 120° Spannweite); die
   „freie Seite"-Heuristik des Mockups wird nicht nachgebaut (10 Marker).
